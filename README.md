# Multimodal cab seat pressure analysis system based on time-series design
# 基于时序设计的多模态驾驶室座椅压力分析系统

## 项目简介

本项目是一个专门用于分析驾驶室座椅压力传感器数据的时序数据分析工具。通过采集用户在座椅上的压力分布数据，系统可以分析不同体重组别的压力变化趋势、稳定性指标以及时序特征，为座椅设计优化和人机工程学研究提供数据支持。

## 核心功能

- **时序数据分析**: 对100帧（20秒）的时序压力数据进行全面分析，包括压力变化率计算和导数分析
- **体重分组**: 自动按四分位数将用户分为四个体重组（轻量组、中轻量组、中重量组、重量组）
- **稳定性评估**: 计算稳定期的平均压力、变异系数和稳定度指标，量化座椅压力分布的稳定性
- **可视化展示**: 生成多种分析图表，包括压力变化曲线、散点图等
- **阈值检测**: 自动识别压力快速下降期和缓慢下降期的分界点

## 数据说明

### 输入数据格式

数据文件采用制表符分隔的格式，包含以下关键字段：

| 字段 | 说明 |
|------|------|
| `data_id` | 样本索引 |
| `user_id` | 用户索引，同一用户会进行三次数据采集 |
| `user_height` | 用户身高 |
| `user_weight` | 用户体重 |
| `unique_code` | 采样索引，同一用户三次采集对应三个不同的unique_code |
| `posture_type` | 姿态类型（0代表正坐） |
| `m_mhg` | 所有传感器数据总和 |
| `m_data` | 采样数据矩阵（24x10的压力传感器矩阵，字符串格式） |

每个unique_code包含100帧数据，总计20秒，作为时序数据进行处理。

### 输出结果

程序运行后会生成以下文件：

- `完整分析数据.csv` - 包含时间帧标记和平均压力的完整数据
- `时间分析结果.csv` - 按时间分组的分析结果
- `稳定期分析数据.csv` - 每个用户的稳定期统计指标
- `压力分析图表.png` - 三联图，包含不同体重组的压力变化、总体压力变化及变化率分析
- `稳定期压力散点图.png` - 个人稳定期平均压力与体重的关系
- `稳定期稳定性散点图.png` - 个人稳定期变异系数分析
- `平均稳定度散点图.png` - 个人平均稳定度指标分析

## 分析指标说明

### 稳定性指标

- **稳定期平均压力** (`stable_avg_pressure`): 去除初期波动后稳定期的压力均值
- **标准差** (`stable_std`): 压力值的离散程度
- **变异系数** (`stable_cv`): 标准差/均值，表示相对稳定性（值越小越稳定）
- **平均稳定度** (`stable_degree`): 1/(1+变异系数)，值越接近1表示越稳定

### 时序分析

- **压力变化率（导数）**: 计算压力随时间的变化速度
- **阈值点**: 自动识别压力从快速下降转为缓慢下降的时间点
- **快速下降区域**: 压力快速变化的初始阶段
- **缓慢下降区域**: 压力趋于稳定的后期阶段
